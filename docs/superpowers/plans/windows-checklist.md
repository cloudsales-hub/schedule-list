# 윈도우 사용자 확인 목록

리눅스 개발 환경에서는 윈도우 화면을 직접 띄울 수 없어서, 아래는 설치 후 직접 확인해야 합니다. 각 항목은 "하면 → 이렇게 되어야 함"입니다. 안 되는 항목이 있으면 번호와 함께 알려 주세요.

- [ ] 1. 설치 후 실행하면 → 위젯이 화면 **오른쪽 위**에 나타난다.
- [ ] 2. `Win+J`를 누르면 → 가운데에 입력창이 뜨고, `내일 오전까지 견적서`를 쓰면 "마감 내일(…) 오전"으로 미리 보인다. Enter로 저장하면 위젯 🔥 급한 것에 나타난다.
- [ ] 3. 엑셀 등 다른 창을 위에 띄우면 → 위젯이 가려지고 업무를 방해하지 않는다.
- [ ] 4. `Win+D`(바탕화면 보기)를 눌러도 → 위젯이 보인다. (안 보이면 알려 주세요. 위젯을 바탕화면 레이어에 붙이는 방식으로 바꾸는 후속 작업이 필요합니다.)
- [ ] 5. 위젯의 빈 곳을 클릭하면 → 대시보드가 열리고 달력, 오늘/임박, 일정, 할일 네 칸과 배너가 보인다. 창을 닫아도 위젯은 계속 떠 있다.
- [ ] 6. 설정에서 단축키를 `Alt+₩` 등으로 바꾸면 → 바로 적용된다. 이미 다른 프로그램이 쓰는 키면 빨간 안내가 나오고 이전 키가 유지된다. `Win+M` 같은 윈도우 예약 키는 거절된다.
- [ ] 7. 두 번째 PC에 설치하고 같은 OneDrive 폴더를 고르면 → 같은 목록이 보인다. 한쪽에서 적은 메모가 몇 초 안에 다른 쪽에 나타난다.
- [ ] 8. 컴퓨터를 다시 켜면 → 위젯이 자동으로 뜬다.
- [ ] 9. 설정에서 배너 크기(작게/보통/크게)와 내 이미지 선택, "기본 그림으로"가 바로 반영된다.
- [ ] 10. 트레이 아이콘을 누르면 → 위젯이 5초간 맨 앞으로 올라왔다가 다시 내려간다. 우클릭 → 종료로 앱이 꺼진다.
