# 일정·할일 위젯

바탕화면에서 바로 보이는 일정·할일 위젯입니다. 일하다가 전화를 받거나 말을 들었을 때 `Alt+~`를 눌러 한 줄로 적어 두면, 급한 순서대로 바탕화면에 보여 줍니다. (윈도우 전용)

## 이런 것을 합니다

- **바탕화면 위젯**: 🗓 일정, 🔥 급한 것(마감 빠른 순), 📝 할일 목록. 위쪽의 ⚙를 누르면 설정 창이 열립니다.
- **빠른 메모**: `Alt+~` → 입력 → Enter. `내일 오전까지 견적서`처럼 쓰면 마감을 알아서 읽습니다. Tab으로 일정↔할일을 바꿉니다.
- **두 PC 동기화**: 같은 OneDrive 폴더를 쓰면 노트북과 데스크톱에 같은 목록이 보입니다. (서버·로그인 없음)

## 설치 방법

1. GitHub의 이 저장소에서 **Actions → build-windows**로 들어가 가장 최근 실행을 엽니다.
2. 맨 아래 **Artifacts**의 `ScheduleWidget-installer`를 내려받아 압축을 풉니다.
3. 안에 있는 `.exe`를 실행해 설치합니다. ("Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누르세요. 개인용 프로그램이라 서명이 없어서 나오는 안내입니다.)
4. 설치가 끝나면 위젯이 화면 오른쪽 위에 나타납니다. 위젯 위쪽의 ⚙를 눌러 데이터 폴더를 확인하세요.

### 두 번째 PC에 설치할 때

같은 방법으로 설치한 뒤 설정에서 **첫 번째 PC와 같은 OneDrive 폴더**를 고르세요. 두 PC 모두 OneDrive가 켜져 있어야 합니다.

## 사용 팁

- 단축키는 설정에서 바꿀 수 있습니다. (두 키 이상 조합, 예: `Alt+Z`)
- 위젯이 다른 창에 가려졌다면 작업표시줄 오른쪽 트레이 아이콘을 누르면 5초간 맨 앞으로 올라옵니다.
- 완전히 끄려면 트레이 아이콘 우클릭 → 종료.
- 데이터는 선택한 폴더의 `schedule-data.json` 한 파일에 저장됩니다. 파일이 깨지면 `.corrupt-…` 이름으로 따로 보관하고 새로 시작합니다.

## 개발자용

```
npm ci
npm test               # 화면·로직 테스트
cargo test -p datafile # 파일 저장 테스트
npm run tauri dev      # 개발 실행(윈도우)
```

`v*` 태그를 푸시하거나 Actions에서 수동 실행하면 설치 파일이 만들어집니다.
